## Portfolio Publish Checklist

### Before commit

1. Set repo-local real-name git identity
2. Run:
   - `npm audit` (0 high/critical) and `npm run build`
3. Add at least one real screenshot, still, or GIF reference
4. Confirm homepage and both project routes are polished
5. Add a clear stack summary

### Before push

1. Confirm the remote should be `jeremy-renger/portfolio`
2. Confirm this app is strong enough to pin on GitHub and use on LinkedIn
3. Confirm no non-portfolio branding is foregrounded
